Une **orthophoto** est une image corrigée géométriquement pour être utilisée comme un document mesurable. En drone, elle ressemble à une grande photo vue du dessus, mais elle est recalée dans un système de coordonnées.

## Différence avec une simple photo

Une photo brute contient de la perspective : les objets hauts penchent, les distances varient selon le relief et l'angle de prise de vue. Une orthophoto corrige ces effets pour se rapprocher d'une vue cartographique.

## Usage terrain

On l'utilise pour mesurer, annoter, contrôler une emprise, produire un fond de plan ou livrer une vue lisible du chantier.

## Le piège classique

Une orthophoto peut être belle mais fausse si le modèle 3D, le MNT/MNS ou le géoréférencement sont mauvais. La qualité visuelle ne garantit pas la précision.
