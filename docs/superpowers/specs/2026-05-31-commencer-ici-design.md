# Page "Commencer ici" - Design editorial

## Objectif

Creer une page `/commencer-ici/` qui oriente deux profils sans les melanger :

- le debutant qui arrive dans la topographie moderne sans connaitre les termes ;
- le professionnel ou semi-pro qui connait deja le terrain et veut trouver vite des contenus utiles, des comparatifs, des workflows et des ressources materiel.

La page doit devenir le sas d'entree principal du site. Elle doit expliquer Topolia, guider la lecture, renforcer le maillage interne, preparer les pages ressources avec affiliation et donner envie de s'abonner a la newsletter.

## Positionnement editorial

La page doit parler comme Topolia :

- tutoiement direct ;
- phrases simples ;
- ton terrain, humain, concret ;
- zero jargon gratuit ;
- aucune promesse marketing ;
- pas de contenu invente ou approximatif.

Le texte doit donner l'impression d'un topographe qui explique calmement par ou commencer, pas d'un assistant IA qui enumere des definitions.

Exemple de ton attendu :

> Si tu debutes, ne commence pas par comparer 12 scanners. Commence par comprendre ce qu'est un nuage de points, comment on le produit, et pourquoi le calage fait souvent la difference entre un chantier propre et un fichier inutilisable.

## Publics vises

### Debutant

Profil :

- decouvre le LiDAR, la photogrammetrie ou la topographie 3D ;
- ne connait pas encore les sigles comme RTK, GCP, MNT, MNS, SLAM ;
- cherche une progression claire ;
- peut etre etudiant, droniste, architecte, artisan, technicien ou curieux motive.

Besoin :

- comprendre les bases sans etre noye ;
- savoir quels mots apprendre en premier ;
- savoir quels articles lire dans quel ordre ;
- eviter les achats materiel trop rapides.

### Pro terrain

Profil :

- utilise deja drone, scanner, station, GNSS ou logiciels de nuage de points ;
- cherche des retours terrain, tests materiel, workflows et comparatifs ;
- veut gagner du temps ou verifier ses choix ;
- peut etre geometre, bureau d'etudes, ingenieur BTP, topographe independant ou droniste pro.

Besoin :

- acceder vite aux comparatifs ;
- trouver des methodes concretes ;
- lire des retours chantier anonymises ;
- trouver des ressources materiel/logicielles utiles.

## Structure de la page

### 1. Hero

H1 recommande :

> Commencer en topographie moderne

Sous-titre :

> Drone, LiDAR, scanner 3D, nuages de points : Topolia t'aide a comprendre les bases, choisir les bons outils et eviter les pieges classiques du terrain.

CTA principaux :

- "Je debute" vers la section debutant ;
- "Je suis deja sur le terrain" vers la section pro.

Le hero doit rester court. La page doit montrer rapidement les deux parcours.

### 2. Section "Si tu debutes"

Objectif : creer un chemin de lecture rassurant.

Contenu :

- expliquer qu'il n'est pas necessaire de tout comprendre d'un coup ;
- presenter les notions a apprendre en premier ;
- lier vers les fiches glossaire existantes ;
- proposer 3 a 5 lectures prioritaires.

Notions prioritaires :

- nuage de points ;
- LiDAR ;
- photogrammetrie ;
- RTK ;
- GCP ;
- MNT ;
- MNS ;
- SLAM.

Pattern recommande :

```text
1. Comprendre ce qu'on mesure
2. Comprendre comment on produit la donnee
3. Comprendre comment on la cale
4. Comprendre comment on la livre
```

### 3. Section "Si tu es deja sur le terrain"

Objectif : montrer que la page n'est pas seulement scolaire.

Contenu :

- orienter vers les comparatifs materiel ;
- orienter vers les workflows ;
- orienter vers les chantiers anonymises ;
- orienter vers les outils logiciels et ressources.

Liens internes prioritaires :

- article Matrice 4E ;
- article Zenmuse L3 ;
- article LiDAR HD IGN ;
- article workflow drone complet ;
- article PDAL ;
- comparatif RTC360 vs Faro Focus ;
- index chantiers ;
- page ressources photogrammetrie drone.

### 4. Section "Choisir son materiel sans se faire pieger"

Objectif : preparer l'affiliation sans casser la confiance.

Angle editorial :

- ne pas pousser l'achat trop tot ;
- expliquer que le bon materiel depend du chantier, du livrable, du budget et du niveau ;
- distinguer accessoires terrain, capteurs, ordinateur, stockage, logiciels.

Message cle :

> Le meilleur achat, ce n'est pas toujours le capteur le plus cher. C'est souvent l'accessoire ou le workflow qui evite de refaire un chantier.

Liens :

- page ressources existante `/ressources/outils-drone-photogrammetrie` ;
- futurs hubs materiel drone, scanner statique, LiDAR drone, PC photogrammetrie.

Affiliation :

- mentionner clairement que certaines pages ressources peuvent contenir des liens affilies ;
- garder une formulation transparente et non agressive.

### 5. Section "Les contenus a lire en premier"

Objectif : proposer une selection guidee plutot qu'un listing brut.

Format recommande :

- 5 cartes editoriales ;
- chaque carte explique pourquoi lire ce contenu ;
- melange entre bases, pratique et materiel.

Selection initiale :

1. Nuage de points - comprendre l'objet central.
2. LiDAR HD IGN - manipuler une vraie donnee gratuite.
3. Workflow drone complet - voir une chaine de production.
4. DJI Matrice 4E - exemple de test terrain materiel.
5. PDAL - comprendre l'automatisation des nuages de points.

### 6. Section newsletter

Objectif : convertir sans forcer.

Angle :

> Une fois par semaine : une astuce terrain, un retour materiel ou une methode pour mieux traiter tes donnees 3D.

La newsletter doit etre presentee comme un prolongement pratique, pas comme une promo.

### 7. FAQ SEO

Ajouter une FAQ courte en bas de page.

Questions recommandees :

- Par quoi commencer en topographie 3D ?
- Quelle difference entre LiDAR et photogrammetrie ?
- Faut-il un drone RTK pour faire de la photogrammetrie ?
- Quel logiciel utiliser pour ouvrir un nuage de points ?
- Quel materiel acheter en premier pour debuter ?

Les reponses doivent etre courtes, sourcables, et renvoyer vers les articles/glossaire quand possible.

## Regles SEO

Requete cible :

- commencer topographie moderne ;
- debuter en topographie 3D ;
- apprendre LiDAR photogrammetrie ;
- debuter drone photogrammetrie ;
- comprendre nuage de points.

### Meta

Title recommande :

> Commencer en topographie moderne : drone, LiDAR, scanner 3D

Description recommandee :

> Tu debutes en topographie 3D, LiDAR ou photogrammetrie ? Topolia t'oriente avec les notions a connaitre, les articles a lire et les outils utiles sur le terrain.

### Structure Hn

- H1 unique : Commencer en topographie moderne
- H2 : Si tu debutes
- H2 : Si tu es deja sur le terrain
- H2 : Choisir son materiel sans se faire pieger
- H2 : Les contenus a lire en premier

### Maillage interne

Chaque terme technique central doit pointer vers le glossaire si une fiche existe.

Chaque section doit proposer des liens vers :

- au moins un article ;
- au moins une fiche glossaire ou page index ;
- au moins une page conversion douce, comme newsletter ou ressources.

## Regles de sources

Les informations factuelles doivent etre verifiees avant redaction.

Sources prioritaires :

- IGN / Geoservices pour LiDAR HD, MNT, MNS, donnees publiques ;
- EASA, DGAC ou Service-Public pour les regles drone ;
- documentation CloudCompare pour fonctions CloudCompare ;
- documentation PDAL pour pipelines et traitements nuage de points ;
- documentation Agisoft pour Metashape ;
- pages constructeurs officielles pour les specs materiel ;
- retours terrain Topolia quand il s'agit d'opinion ou d'experience.

Regle stricte :

- ne pas inventer de chiffres de precision, prix, autonomie, portee ou performance ;
- si une information depend du materiel, de la mission ou de la reglementation, le dire ;
- distinguer clairement faits sources et opinion terrain.

## Regles glossaire

Quand un terme technique apparait dans la page :

1. Si la fiche existe, mettre un lien interne vers cette fiche.
2. Si la fiche n'existe pas et que le terme aide vraiment le lecteur, creer une fiche glossaire.
3. Si le terme est secondaire, l'expliquer en une phrase et eviter d'en faire un concept central.

Fiches existantes a lier :

- `nuage-de-points`
- `lidar`
- `photogrammetrie`
- `rtk`
- `gcp`
- `mnt`
- `mns`
- `slam`
- `copc`
- `recalage`

Fiches a creer si les termes sont utilises :

- `gsd`
- `ppk`
- `las`
- `laz`
- `e57`
- `orthophoto`
- `maillage`
- `classification`
- `georeferencement`

Chaque nouvelle fiche glossaire doit suivre le schema existant de `src/content/glossaire/*.mdx` :

- title ;
- date ;
- difficulty ;
- relatedArticles ;
- relatedChantiers ;
- excerpt ;
- body court, clair, avec exemple terrain.

## Design UX

La page doit rester scannable :

- cartes de parcours pour debutant/pro ;
- liens lisibles ;
- sections courtes ;
- pas de mur de texte ;
- CTA modestes ;
- style coherent avec les pages existantes.

Composants reutilisables possibles :

- cartes simples pour parcours ;
- bloc "A lire en premier" ;
- bloc "Terme a connaitre" ;
- `NewsletterInline` existant ;
- `ArticleCard` ou cartes editees manuellement selon le rendu.

## Hors scope

Cette page ne doit pas encore inclure :

- un calculateur GSD ;
- un generateur de plan de vol ;
- un PDF telechargeable ;
- un systeme de parcours interactif ;
- de nouvelles pages piliers completes.

Ces elements pourront etre branches ensuite sur la page.

## Criteres d'acceptation

- La page `/commencer-ici/` existe.
- La navigation principale contient un lien vers la page si l'espace le permet.
- Le contenu oriente clairement debutants et pros.
- Les termes techniques importants sont lies au glossaire.
- Les termes importants absents du glossaire ont une fiche creee.
- La page contient une FAQ SEO courte.
- La page contient une section ressources/materiel transparente sur l'affiliation.
- Le texte ne contient pas de promesses non sourcees.
- Le build Astro passe.
- Le texte respecte le ton Topolia : humain, direct, terrain.
